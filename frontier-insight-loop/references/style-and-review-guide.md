# 文风与 Review 细则

## 一、发布文案文风（平实风格）

用户明确要求"不要太抓人眼球，平实就行"。所有对外文案遵守：

**该做的**
- 像跟同行分享读书笔记的语气：克制、具体、有信息量
- 每条观点尽量带一个可验证的锚点（数据、原文引语、具体机制），不写空泛断言
- 结构：一句平淡引子 → 2-4 个编号段落（每段一个加粗小标题 + 2-4 句）→ 一段收敛感悟
- 结尾感悟留余味，可以有一句轻量的判断，但不煽情

**不该做的**
- 不用"炸裂/颠覆/封神/杀疯了/细思极恐"等标题党词汇
- 不连续使用感叹号；全文感叹号 ≤ 1
- 不用"家人们/谁懂啊/血泪教训"等自媒体口癖
- 不编造原文没有的数据和引语
- 不把个人感悟包装成原文观点——引用事实与个人判断要可区分

## 二、Review 判定细则

每核对一条，必须同时给出三样东西：
1. **判定符号**（✅/⚠️/❌/💡）
2. **原文依据**：引用原文关键句或数据，或指明"原文未提及"
3. **修正动作**：具体到"X 词应改为 Y"或"应补充 Z 限定条件"

判定边界：
- 意思一致、措辞不同 → ✅，不要为改而改
- 方向对但丢了限定条件/关键数据 → ⚠️
- 与原文矛盾、逻辑写反、指鹿为马 → ❌
- 原文有而用户未提、且对理解文章关键 → 💡

对"感悟"类观点不判定对错（观点无对错），只做证据支撑度评估：
- 有原文证据支撑 → 建议保留并可强化
- 与原文证据相悖 → 指出张力所在，让用户自行取舍
- 原文未提但合理外推 → 标记为"这是你的外推，非原文观点"，发布时建议明示

## 三、发布文案模板（推特/X 长帖，中文）

```
<一句平淡引子：读完 XX 的《文章名》，记录一下认知更新>

**1. <小标题，陈述句>**
<2-4 句，带数据或机制细节>

**2. <小标题>**
<...>

**3. <小标题>**
<...>

<一段收敛感悟：把观察提炼成 1-2 层判断，平实收尾>
```

- 总长控制在 250-450 字（不含标题），信息密度优先
- 英文专有名词首次出现给中文译名 + 括号原文（如 版本控制系统 Scion）
