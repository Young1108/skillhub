# 企微表情包导出与迁移

## 背景事实（先读，决定策略）

- 企微本地 `Emotion` 目录只是 **CDN 缓存**；表情列表的权威源在云端，按**企业身份**隔离（每个企业身份一个 `<账号ID>` 目录）。
- 因此：同账号换设备 → 云端自动同步，无需迁移；**换企业/换公司 → 不跟随，官方无批量导入通道**，只能"导出图片 → 新环境重新收藏"。本 skill 解决的就是后一种场景，以及本地备份需求。
- 路径结构、mapping.db 表结构、已知坑见 `references/notes.md`。

## 工作流程

### 1. 导出（macOS，脚本已封装）

```bash
bash <skill-dir>/scripts/export_emotions.sh            # 交互列出并导出全部有缓存的账号
bash <skill-dir>/scripts/export_emotions.sh 1688854942900883 --out ./emo --zip
```

产物：`<out>/<账号ID>/NNN_原文件名` 图片、`manifest.csv`（URL↔文件映射，可追溯）、`index.html` 网格预览页。

脚本自动处理：db 三件套先拷再开（避锁）、无扩展名文件按 mime 补后缀、缺失文件跳过、目录内未登记文件 fallback + md5 去重、`Temp/` 与 `cover_` 封面处理。

### 2. 校验

- 打开 `index.html` 人工抽查：数量合理、gif 能播、无明显坏图。
- 核对 `manifest.csv` 行数与图片数一致；`manifest.unmatched.csv` 若存在，向用户说明哪些文件不在云端索引里。

### 3. 恢复（新设备 / 新企业）

官方不支持批量导入，唯一原生通道：**图片发到会话 → 右键/长按 →「添加到表情」**。

- 少量高频：从 `index.html` 挑选，拖图进聊天窗口逐条收藏。
- 批量：把导出目录作为一个文件夹在企微里发给自己（文件传输助手或自建单聊），逐个点开再收藏；表情顺序需重新长按排序。
- 桌面端比手机端效率高，优先用 Mac/Windows 客户端操作。

### 4. 交付说明

向用户明确边界（区分已验证/推断）：导出的是本地缓存快照，跨设备同账号无需此操作；换企业后表情是否残留可见取决于客户端行为，未实测。

## 边界

- 本脚本只读企微数据目录，不写入、不修改、不删除任何原文件；导出目录默认在当前工作区。
- 仅覆盖 macOS 容器版路径；Windows 路径见 `references/notes.md`，未实测，需现场排查。
- 不做 GUI 自动化批量点击"添加到表情"——无官方接口，模拟点击脆弱且易误操作。
